## 2. Summary

| Severity | Count | IDs |
| --- | --- | --- |
| Critical | 1 | B-01 |
| Major | 10 | B-02 ... B-11 |
| Minor | 7 | B-12 ... B-18 |

The implementation of the HoloOcean coupling is careful (geometry, units, translational chain closure all
check out, section 4). The problems are in what the experiments measure: (i) every surge station-keeping
run puts all horizontal T200s on their reverse branch, which costs about 40 % more power than forward at
equal thrust, so the orientation trade-off and the baseline error spread are dominated by an arbitrary
current direction and an unsupported sign mapping (unchanged in the new EXP3/EXP4, while the new EXP10 uses
the opposite, forward branch); (ii) the native body is perfectly decoupled, isotropic, neutrally buoyant
and carries ground-referenced UE damping: a 1-DOF ODE reproduces the native station-keeping and heave
traces to 5e-7 m, so several "layout" results are properties of that idealisation; (iii) the committed
averaging windows are transient-only and the transits end in different states; (iv) the allocator and the
power manager use different thrust bounds, producing spurious derating.
