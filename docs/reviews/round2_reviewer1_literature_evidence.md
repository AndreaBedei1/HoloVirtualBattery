# Round 2, Reviewer 1: literature and evidence

Scope: `paper/manuscript.md`, `docs/paper/{CLAIM_EVIDENCE_MATRIX,RELATED_WORK_VERIFICATION,COMPARATOR_MATRIX,D_GRADE_PARAMETER_REVIEW}.md`,
`docs/literature/*.md`, the evidence registry (`holoenergy/evidence/data/`), `data/evidence/final_parameter_audit.*`,
`experiments/results/final/decision_case.json`, `experiments/run_decision_case.py`. Read-only review; no repository file changed.

## Verdict

**Major revision (no fatal finding).** Citations are accurate, abstract-only reads are labelled as such, manufacturer values are
consistently called input evidence, and grade counts in the audit reproduce (54 records; A 24, B 12, C 3, D 15; 8 upper-bound-only;
14 unconfigured or unlinked). I found no invented numeric value among those spot-checked. Five major problems remain: the
decision-case "nominal" values are published maxima (one is a family range) and this is not said in the paper; the reference
list omits the sources of records behind headline claims; the audit omits the decision-case records; the comparator conclusion is
generalised beyond what a self-built reproduction can support; and the related-work/novelty framing excludes relevant prior
art that is present in the project's own PDF library.
